# 威胁模型 / Threat model

这份文档说两件事：**这个包在哪里是弱的**，以及**它拒绝声称什么**。
不写这一节的包，等于让读者以为「0 problems」等于「没有问题」。

## 它防住了什么

| 风险 | 机制 |
|---|---|
| 门禁形同虚设（声明了但抓不住缺陷） | 负向对照：注入已知缺陷，断言对应 code 真的报出。少一例即拦发布 |
| 判据与代码脱节（文档说的和实际查的不是一回事） | `CRITERIA.md` 由代码里的判据表逐字生成并比对，`criteria-doc` 判据把关 |
| 改判据却不补对照 | `negative-control-gap`：自有 code 必须 100% 有负向对照 |
| 门禁声明了却没执行器 | `check-gate-wiring.mjs`：每道有 config 的门必须声明 wiring，键名须在执行器源码里按独立标识符出现 |
| 改名留下悬空引用 | `ref-integrity` / `skill-contribution-target-missing` / `scenario-reference-missing` |
| 版本三处不同步 | `doc-version-drift`：README 徽章、版本历史首条、清单三处必须与 `pack.json` 一致 |
| digest 不可复现（行尾漂移） | `.gitattributes` 钉 `eol=lf`；digest 声明 `digestTarget`；`repin-digests` 可复跑 |
| 源账本与禁例表脱节 | `banned-tokens-gap` 阈值 0：新增源必须同步补词干 |
| 数字三处不一致 | `i1_collision_check.py` 对撞摘要／正文／底座 |
| 产物里的占位符漏进正文 | `placeholder-clean` + 报告生成器自带空值自检 |
| 私库位置外泄 | `fileRef-unsafe` 拒绝绝对路径／URL／内网地址 |
| 表达式与刊名泄露 | `banned-tokens` + 文风渲染的反例清单（刊名出现次数须为 0） |
| 静默降级取数 | `wind-provenance` fail-closed，禁重装/绕走，降级须逐项标注 |

## 它防不住什么

**这一节是这份文档存在的理由。**

| 弱点 | 说明 |
|---|---|
| **方法本身对不对，无人验证** | 判据验的是形状、存在与一致，不是「这条方法在金融上是否成立」。这个包无法用自己验证自己 |
| **⑭⑮ 两层的参数是海外样本** | 底本实证来自美国宏观、G10 货币、国际油价、美股标的。A 股涨跌停、T+1、停牌结构性改变波动率持续性，**直接沿用海外 GARCH 参数会错得很自信** |
| **A 股无本地模型竞赛基准表** | 引用模型相对表现时只能说「未获取本地基准」，不能说它更优 |
| **A 股宏观 vintage 未获取** | 实时数据流纪律只能作原则要求，无法真正回溯复现「当时能拿到的数据」 |
| **闸门 C 多为人工核** | 包里没有独立执行器去查断点、复权口径漂移、跨源背离；质检三件套靠产物侧证据自证（`data_qc_out.json`） |
| **命中率样本远不够** | 技能 vs 运气的二项检验要 ≥10 年样本。所以累计命中率必须附无条件基准率与恒定基准，跨 `skill_version` 分组，不得直接加总期数 |
| **不校验 Wind 是否真的可用** | 凭据缺失时 fail-closed，但「Wind 客户端是否装了、是否有权限」取决于本机环境 |
| **语料只有 51 源** | 再宽的框架也受这 51 本的边界约束；框架里没写的机制，它不会替你补 |
| **结构化检索，不是语义检索** | 本体提供实体/关系与检索剖面，不含向量检索；跨层概念关联靠显式关系 |
| **平台校验器不在 CI 内** | `check-pack` 的 3/4/5/6 项依赖 `@zhijian/dsh-expert-library`，CI 里不可得，以 skip note 声明后跳过 |
| **原著原文不可见** | 读者能验证「结论来自哪本书」，但无法在本仓内核对「这本书具体怎么说的」 |

## 它拒绝声称什么

这几条是**有意的克制**，不是能力缺失：

1. **不声称自己的结论正确。** 结论由执行者产出，本包只保证流程与门槛。
2. **不声称闸门 C 是可执行硬门。** 声明为 semantic 并附 `wiring.reason`。
3. **不声称「0 problems」等于「没有问题」。** `CRITERIA.md` 的「不查什么」栏就是这句话的限定。
4. **不声称知识底座覆盖了这个学科的全部。** 51 源是明确的边界。
5. **不声称开箱即用的取数能力。** Wind 未就绪时一律落到退回档，且必须声明档位。
6. **不声称能在非 Windows／非本地环境用。** 有些检查要跑 playwright 与 Python 3.9+。
7. **不把「未获取」填成「大概」。** 取不到就写「未获取」并标原因。
